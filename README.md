# Analisador Léxico

## Sobre

Este projeto foi desenvolvido para a matéria de Linguagens Formais, ministrado por Fabio A. Zanin, da Universidade Regional Integrada do Alto Uruguai e das Missões por Luis Fernando Refatti Boff (103436) e Eduardo Ongaratto (103963).

O objetivo deste analisador léxico é atuar como um autômato na identificação da linguagem L(G) = {x | x ∈ T * e não tenha a's consecutivos}, onde T = {a, b, c} como uma máquina de estados.

A utilização da ferramenta é simples: basta inserir uma cadeia no campo indicado de "Entrada" para verificar em tempo real as mudanças de estado do autômato. Para analisar a sentença digitada, basta apertar a tecla "espaço" para finalizar a cadeia atual.
